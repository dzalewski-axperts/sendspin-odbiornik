# Odbiornik Sendspin z własnym wyglądem

Strona odbiornika Google Cast dla Sendspin (Music Assistant), z innym wyglądem: tło z kolorów okładki, duża okładka, tytuł, wykonawca, postęp, głośność i zegar.

Na podstawie [Sendspin/cast](https://github.com/Sendspin/cast) (Apache License 2.0, plik `LICENSE`). Zmieniony jest tylko `receiver.html` (HTML i CSS). Pliki w `assets/` to niezmienione pliki zbudowane z tamtego projektu (wydanie `ma-2.9`).
